# Stylescape devContainer theme

This repository is two things side by side:

- **a development container** for Stylescape work — `.devcontainer/`,
  `src/.devcontainer/`, `src/devcontainer/` and the bake/compose files in
  `bin/`, documented in the [README](../README.md) and
  [`docs/`](../docs/index.md);
- **a Stylescape theme** — `@stylescape/stylescape-devcontainer`, the navy
  and white of the Stylescape badges as `--ss-*` tokens, documented here.
